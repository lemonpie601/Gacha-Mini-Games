# Gacha Mini Games · 로딩 미니게임

마리나라 엔진 **가챠 포지**용 개인 확장입니다. 챕터·스토리를 **생성하는 동안** 생성 화면 오른쪽에 게임 목록이 나타나고, 생성이 끝나면(완료·실패 모두) 사라집니다. 게임은 이 화면 안에서만 진행되며 게임 진행·보상·생성 요청에는 영향을 주지 않습니다.

말랑 UI(Gacha UI Style · 말랑) 1.11.15까지 들어 있던 로딩 미니게임을 별도 확장으로 분리했습니다. 말랑 없이도 동작하고, 말랑이 켜져 있으면 그 색상 테마와 SD 캐릭터를 씁니다.

## 게임 (12가지)

| 게임 | 쉬움 / 보통 / 어려움 | 방법 |
| --- | --- | --- |
| 지뢰찾기 | 8×8 / 10×10 / 12×12 | 첫 칸은 항상 안전, 우클릭·길게 눌러 깃발 또는 [깃발 모드], 숫자를 누르면 깃발 수가 맞을 때 주변을 한 번에 열기 |
| 사과 상자 | 3분·1~5 / 2분·1~9 / 1분 30초 | 합이 10인 사각형을 드래그해 지우기(합계는 표시하지 않음), 힌트 3회 |
| 2048 | 5×5 / 4×4 / 3×3(목표 256) | 방향키·WASD·스와이프·화면 방향 버튼 |
| 짝 맞추기 | 6쌍 / 8쌍 / 12쌍 | 말랑의 SD 캐릭터가 카드(부족하면 과일) |
| 쿠키 가게 | 목표 6,000·♥5 / 10,000·♥4 / 15,000·♥3 | 슈의 라면집 방식. 아래 참고 |
| 디저트 핀볼 | 공 5개·세이브 10초 / 공 3개·세이브 5초 / 공 3개·세이브 없음 | 아래 참고 |
| 비스킷 벽돌깨기 | 하트 5·넓게 / 하트 3·초코 한 줄 / 하트 3·좁고 빠르게 | 마우스·←→·◀▶로 뒤집개 이동, 스페이스·탭으로 발사. 뒤집개 끝에 맞을수록 비스듬히 튀고, 초코 비스킷은 두 번 맞혀야 깨짐. 떨어지는 간식: 길 = 12초 동안 긴 뒤집개, ♥ = 하트 +1. 다 깨면 다음 스테이지(조금 더 빠르게) |
| 스네이크 | 12×12 느리게 / 15×15 / 18×18 빠르게 | 방향키·WASD·스와이프·방향 버튼, 먹이는 테마 그림 |
| 딸기 우유 레시피 | 재료 4 천천히 / 4 / 6 빠르게 | 재료가 빛나는 순서를 기억해 따라 누르기, 한 단계마다 하나씩 길어짐 |
| 초코칩 터뜨리기 | 8×6·3색 / 10×8·4색 / 12×9·5색 | 같은 색이 2개 이상 붙은 덩어리 누르기, 클수록 점수↑, 다 비우면 +100 |
| 꽃밭 퍼즐 | 3×3 / 4×4 / 5×5 | 빈칸 옆 조각을 밀어 1부터 순서대로 |
| 별 밝히기 | 4×4 / 5×5 / 6×6 | 누르면 그 별과 상하좌우가 켜졌다 꺼짐, 모든 별 밝히기 |

### 쿠키 가게 (슈의 라면집 방식)

- 가게 앞: 차양과 간판, 창문, 메뉴판, 계산대. 손님은 최대 3명까지 줄을 서고, 머리 위 말풍선에 주문(플레인·초코칩·크림·스페셜=둘 다)과 기다림 막대가 있습니다. 오래 기다리면 표정이 굳고 화를 내다(💢) 결국 떠나며, 그때마다 하트(♥)가 하나 줄어듭니다.
- 오븐 4개. 선반에서 도구(버터·불 켜기·반죽·설탕·초코칩·크림·접시)를 고르고 오븐을 누릅니다. 숫자키 1~7로도 고를 수 있습니다.
- 순서: 버터 → 불 켜기 → 예열 램프가 초록이 되면 반죽 → 설탕 → 굽기. 오븐 다이얼 바늘이 노란 구간에 들어가 김이 나면(노릇노릇) 주문대로 토핑하고 접시로 냅니다. 그 쿠키를 주문한 손님이 받고, 없으면 가장 오래 기다린 손님이 받습니다.
- 값: 1,000원에서 실수마다 깎입니다. 덜 익음 −700 / 너무 구움 −400 / 설탕 없음 −300 / 시킨 토핑 없음 −250 / 버터 없음 −200 / 예열 전에 반죽(납작) −200 / 안 시킨 토핑 −150 / 토핑을 늦게 −150 / 토핑을 일찍(녹음) −100. 800원 이상을 빨리 내면 팁 +200. 손님은 가장 큰 실수를 말합니다.
- 불 켠 오븐을 너무 오래 두면(빈 오븐도) 연기가 나다 탑니다. 탄 오븐을 누르면 예비 오븐(3개)으로 바꾸고, 예비가 없으면 그 자리는 고장 납니다. 하트나 오븐이 모두 사라지면 가게 문을 닫고, 목표 금액을 모으면 성공입니다. 최고 기록은 목표를 가장 빨리 모은 시간입니다.
- 다른 게임으로 넘어가면 가게는 멈춥니다. 말랑이 켜져 있으면 손님은 이 세계의 SD 캐릭터, 아니면 직접 그린 손님입니다.

### 디저트 핀볼

- 스페이스·↓·Enter(또는 [발사])를 꾹 눌렀다 떼면 공이 나갑니다. 오래 누를수록 셉니다.
- 플리퍼: ←·Z·A·Shift 왼쪽, →·D·M·/ 오른쪽. 터치는 테이블 왼쪽·오른쪽 절반, 또는 아래 버튼.
- 도넛 범퍼 100점, 플리퍼 위 새총 10점, 위쪽 별 레인 50점. 별 3개를 다 켜면 +500점에 배수가 올라갑니다(최대 ×5, 공을 잃으면 ×1). 플리퍼를 누르면 켜진 별이 옆으로 옮겨 갑니다.
- 발사 직후 볼 세이브 시간 안에 빠진 공은 한 번 돌려받습니다. 최고 기록은 최고 점수입니다.

- 난이도는 버튼에 마우스를 올리면 자세히 보이며, 바꾸면 새 판이 시작됩니다.
- 끝나면 결과 카드와 [다시 하기]가 나옵니다. 결과 카드 바깥을 누르면 판을 다시 볼 수 있습니다.
- [크게 보기]로 게임 영역을 넓히고, [게임 접기]로 게임을 닫습니다.
- 최고 기록은 이 브라우저에만 저장됩니다.

## 테마

말랑의 색상 프리셋에 따라 상자 게임의 과일과 지뢰찾기 판이 바뀝니다. 그라데이션 없이 단색으로 그립니다.

| 말랑 프리셋 | 상자 게임 | 지뢰찾기 |
| --- | --- | --- |
| 크림 코코아 (말랑 없을 때 기본) | 🍎 사과 상자 | 노란 칸, 빨간 깃발, 폭탄 |
| 딸기 우유 | 🍓 딸기 상자 | 분홍 칸 |
| 민트 초코 | 🍏 청사과 상자 | 민트 칸, 갈색 깃발, 지뢰는 초코칩 |
| 라벤더 | 🍇 포도 상자 | 연보라 칸 |
| 밤하늘 | ⭐ 별 상자 | 남색 칸, 깃발 대신 금색 별, 지뢰는 빛나는 구슬 |

말랑에서 색을 직접 고른 경우 바탕색이 어두우면 밤하늘, 아니면 크림 모양을 씁니다.

## 설치

마리나라 설정의 개인 확장에서 `Gacha-Mini-Games-1.3.0.personal-extension.zip`을 설치하거나, 로컬 서버에 바로 넣으려면:

```
node tools/install.mjs 7860
```

## 테스트

```
node tools/test-games.mjs
node Gacha-Minigames/tools/test-games-browser.cjs   (상위 폴더에서, Edge 필요)
```

## 1.2.0

쿠키 가게를 슈의 라면집처럼 다시 만들었습니다: 주문·기다림·하트가 있는 손님 줄, 버터·예열·설탕 단계, 다이얼과 예열 램프가 달린 오븐, 실수별 가격과 팁. 가게 앞·오븐·도구·손님을 새로 그렸습니다. 디저트 핀볼을 추가했습니다.

## 1.1.0

게임 6가지 추가: 쿠키 가게(슈의 라면집 방식), 스네이크, 딸기 우유 레시피, 초코칩 터뜨리기, 꽃밭 퍼즐, 별 밝히기. 게임 목록을 두 줄 카드로 바꿨습니다. 사과 상자에서 드래그할 때 합계 숫자를 더 이상 보여 주지 않습니다.

## 1.0.1

가챠 포지를 처음 열 때, 세계를 바꿀 때 잠깐 뜨는 로딩 화면에서도 미니게임이 나오던 문제를 고쳤습니다. 게임은 이미 쓰인 장면을 불러올 때도 같은 "Generating story…" 화면을 잠깐 보여 줍니다. 이제 게임이 시작 중이거나 이미 쓰인 챕터를 여는 중이면 띄우지 않고, 그 밖에는 생성 화면이 2.5초 넘게 이어질 때만 미니게임을 띄웁니다.
