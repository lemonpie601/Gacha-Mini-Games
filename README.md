# Gacha Mini Games · 로딩 미니게임

마리나라 엔진 **가챠 포지**용 개인 확장입니다. 챕터·스토리를 **생성하는 동안** 생성 화면 오른쪽에 게임 목록이 나타나고, 생성이 끝나면(완료·실패 모두) 사라집니다. 게임은 이 화면 안에서만 진행되며 게임 진행·보상·생성 요청에는 영향을 주지 않습니다.

말랑 UI(Gacha UI Style · 말랑) 1.11.15까지 들어 있던 로딩 미니게임을 별도 확장으로 분리했습니다. 말랑 없이도 동작하고, 말랑이 켜져 있으면 그 색상 테마와 SD 캐릭터를 씁니다.

## 게임

| 게임 | 쉬움 / 보통 / 어려움 | 특징 |
| --- | --- | --- |
| 지뢰찾기 | 8×8·10개 / 10×10·18개 / 12×12·30개 | 첫 칸은 항상 안전, 우클릭·길게 눌러 깃발 또는 [깃발 모드], 숫자를 누르면 깃발 수가 맞을 때 주변을 한 번에 열기, 최단 기록 |
| 사과 상자 | 3분·1~5 / 2분·1~9 / 1분 30초 | 합이 10인 사각형을 드래그(또는 두 모서리 누르기)해 지우기, 선택 범위 테두리와 합계 표시(10이면 초록·넘으면 빨강), 힌트 3회, 더 지울 게 없으면 종료, 최고 점수 |
| 2048 | 5×5 / 4×4 / 3×3(목표 256) | 방향키·WASD·스와이프·마우스 드래그·화면 방향 버튼, 최고 점수 |
| 짝 맞추기 | 6쌍 / 8쌍 / 12쌍 | 말랑의 SD 캐릭터가 카드(부족하면 과일), 시도 횟수·시간, 최소 시도 기록 |

- 난이도는 버튼에 마우스를 올리면 판 크기·시간이 보이며, 바꾸면 새 판이 시작됩니다.
- 끝나면 결과 카드와 [다시 하기]가 나옵니다. 결과 카드 바깥을 누르면 판을 다시 볼 수 있습니다.
- [크게 보기]로 게임 영역을 넓히고, [게임 접기]로 게임을 닫습니다.
- 최고 기록은 이 브라우저에만 저장됩니다.

## 테마

말랑의 색상 프리셋에 따라 상자 게임의 과일과 지뢰찾기 판이 바뀝니다. 그라데이션 없이 단색으로 그립니다.

| 말랑 프리셋 | 상자 게임 | 지뢰찾기 |
| --- | --- | --- |
| 크림 코코아 (말랑 없을 때 기본) | 🍎 사과 상자 | 노란 칸, 빨간 깃발, 폭탄 |
| 딸기 우유 | 🍓 딸기 상자 | 분홍 칸 |
| 민트 초코 | 🍏 청사과 상자 | 민트 칸, 갈색 깃발, 지뢰는 초코칩 |
| 라벤더 | 🍇 포도 상자 | 연보라 칸 |
| 밤하늘 | ⭐ 별 상자 | 남색 칸, 깃발 대신 금색 별, 지뢰는 빛나는 구슬 |

말랑에서 색을 직접 고른 경우 바탕색이 어두우면 밤하늘, 아니면 크림 모양을 씁니다.

## 설치

마리나라 설정의 개인 확장에서 `Gacha-Mini-Games-1.0.0.personal-extension.zip`을 설치하거나, 로컬 서버에 바로 넣으려면:

```
node tools/install.mjs 7860
```

## 테스트

```
node tools/test-games.mjs
node Gacha-Minigames/tools/test-games-browser.cjs   (상위 폴더에서, Edge 필요)
```
